# Data Backup System

## Description
This project is a Data Backup System developed in Java.
It allows users to save and restore data using file handling.

## Features
- Create backup
- Restore backup
- File storage using serialization

## Technologies Used
- Java
- File I/O
- Serialization
- Scanner

## How to Run
1. Open in VS Code / NetBeans
2. Compile program
3. Run DataBackupSystem.java

## Sample Output
=== DATA BACKUP SYSTEM ===
1. Create Backup
2. Restore Backup
3. Exit
